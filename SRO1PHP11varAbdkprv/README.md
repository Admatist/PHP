# Доска объявлений факультета (СРО по PHP)

## Описание проекта

Веб-приложение для публикации, фильтрации и управления учебными объявлениями[cite: 14]. Разработано в рамках СРО по дисциплине «Программирование на PHP» (Вариант 11) на чистом PHP 8.4[cite: 6, 14].

## Инструкция по запуску

1. Откройте терминал в папке проекта (`faculty-board`).
2. Запустите встроенный сервер PHP:
   ```bash
   php -S localhost:8000 -t public
   ```
